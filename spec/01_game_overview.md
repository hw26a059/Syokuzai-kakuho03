# 食材目利きゲーム 仕様書：全体概要

## 1. ゲーム概要
本作は、お肉、お魚、野菜の「目利き（鮮度や旬の選び方）」をテーマにした、クイズ形式のカジュアルゲームです。
日常の買い物に役立つ実用的な知識を手軽に楽しく学ぶことができます。

## 2. ターゲット層
- 主婦・主夫
- 一人暮らしを始めたばかりの人
- 食材の選び方や旬に興味がある一般消費者

## 3. 主要コンセプト
- **「目利き」を楽しく学ぶ**: クイズを通じて、食材の鮮度や美味しい「旬」の見分け方を習得する。
- **学びが料理に繋がる**: 獲得した食材を使って料理を行い、クイズの成績がそのまま料理の出来栄えに直結する。
- **知識のコレクションと学習**: クイズに正解して「食材図鑑」を解放・充実させる楽しさと、本格的な「調理レシピ」をいつでも閲覧できる実用的な学習体験を提供する。

## 4. 全体ゲームフロー
1. **レシピ選択・食材カスタマイズ**：料理レシピを選び、最低必要食材数や固定条件を満たすように具材を選択。
2. **食材の目利きクイズ・ミニ解説**：選んだ食材の鮮度や旬に関するクイズに挑戦し、解説を閲覧（正解した食材は「食材図鑑」に解放）。
3. **調理フェーズ（手順並べ替えパズル）**：正しい調理の手順を組み立てる穴埋めパズルに挑戦（制限時間なし）。
4. **結果評価・スコアリング**：目利き・調理の両パートが60%以上で料理大成功。両パートの合計スコア（最大200点）がプレイヤーの累計スコアに加算され、結果を表示（※料理の自由命名、料理図鑑、ランキングは廃止）。

## 5. 閲覧・図鑑機能
- **調理レシピ**: 各料理の詳細な作り方やコツなどをいつでも確認できる（最初から全解放）。
- **食材図鑑**: 目利きクイズで正解した食材の詳細情報（目利きポイントや豆知識など）がコレクション・解放される。
