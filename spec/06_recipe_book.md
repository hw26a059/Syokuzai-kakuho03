# 食材目利きゲーム 仕様書：調理レシピ仕様

## 1. 概要
ゲーム内に登場する料理の詳しい作り方・レシピをいつでも閲覧できる機能です。
パズルの答え合わせや自炊・料理の学習に役立つよう、調理パズルよりも一歩踏み込んだ実践的な調理情報を提供します。

---

## 2. 解放条件
- **最初から全解放**:
  - ゲーム開始時点から、すべての料理レシピを自由に閲覧可能です（ゲーム進行によるロックはなし）。

---

## 3. レシピの掲載情報
各料理レシピには、以下の項目が構造化されて掲載されます。

1. **料理基本情報**:
   - 料理名（例：カレーライス、肉じゃが）
   - カテゴリ（カレー、汁物、和食、中華など）
   - 調理目安時間 / 難易度
2. **基本材料・食材**:
   - 基本具材（必須食材）およびおすすめの追加食材
3. **詳しい調理手順（ステップ解説）**:
   - 調理パズルの簡易手順より詳しい情報（火の強さ、煮込み時間、切り方の具体的な大きさ、灰汁の取り方など）。
   - 例（カレーライスの場合）:
     - 1. 食材の準備：玉ねぎは繊維に沿って薄切り、にんじん・じゃがいもは一口大の乱切りにする。じゃがいもは水にさらして煮崩れを防ぐ。
     - 2. 炒め：厚手の鍋に油を熱し、中火で肉を色が変わるまで炒め、玉ねぎを加えて透き通るまで炒める。
     - 3. 具材の煮込み：じゃがいも、にんじんを加え、油が回ったら水を注ぐ。沸騰したら弱火にし、丁寧にあくを取り除きながら約15〜20分煮込む。
     - 4. ルウの投入：火を一度完全に止め、カレールウを割り入れて完全に溶かす。
     - 5. 仕上げ煮込み：再び弱火にかけ、焦げ付かないよう底から混ぜながら、とろみがつくまで約10分煮込んで完成。
4. **プロの目利き・調理ワンポイント**:
   - 料理をより美味しく仕上げるための下処理のコツや、鮮度の良い食材を使った場合の風味の違いについての解説。

---

## 4. UI・操作仕様
- 画面上部のタブナビゲーションまたはメインメニューから「調理レシピ」を選択して遷移。
- レシピ一覧はカテゴリ別に整理され、カードまたはリスト形式で表示。
- レシピを選択すると、詳細な調理手順とポイントが読みやすいレイアウトで展開。
