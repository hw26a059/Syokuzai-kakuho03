# 食材目利きゲーム 仕様書：ゲームシステム

## 1. クイズシステム（目利き）
- **出題カテゴリ**: お肉、お魚、野菜
- **出題内容**:
  - 食材の鮮度の見分け方（色、つや、ドリップの有無など）
  - 食材の旬の時期や、旬のものの特徴（例：春キャベツと冬キャベツの違いなど）
- **出題数**: 
  - プレイヤーが選択した「料理レシピ」に使う食材の数（「具材」）に応じて変動。
  - 例：カレーライスで「じゃがいも」「にんじん」「玉ねぎ」「牛肉」を選択した場合、問題数は4問（※具材のカスタマイズ状況によって基本食材＋トッピング具材はクイズ対象から除外されることがあります）。
- **出題順**:
  - プレイヤーがカスタマイズした食材の並び（または定義順）に基づき、肉・魚・野菜といったカテゴリを跨いで連続で出題。
- **難易度設定とゲームルール**:
  - クイズ開始前に「簡単」と「難しい」の2つの難易度から選択できる。デフォルトは「簡単」が選択。
- **制限時間**:
  - なし（「簡単」「難しい」ともに時間制限は設けず、プレイヤーがじっくり考えて回答可能とする）。
- **回答方式と難易度別の挙動**:
  - **簡単**:
    - 写真付き問題（じゃがいも・にんじん）：ヒントとなる説明文（テキスト文章）は非表示となり、**「写真（画像アセット）のみ」**からプレイヤー自身の目で直接目利きを行う（2択）。
    - その他の食材（写真アセットのない食材）：従来のテキスト選択肢形式（3択）で出題。
  - **難しい**:
    - テキスト問題：選択肢がより紛らわしい表現に差し替わった4択形式で出題。
    - ※難しいモードの写真問題については、今後現在の2つの写真に加えてさらに2つの写真を追加し、計4枚の写真から目利きする4択写真形式へ拡張予定（現時点では簡単モードのみ写真のみ形式を先行実装）。
- **写真の選択肢構成**:
  - 最も新鮮・旬の状態（正解）、少し時間が経過してドリップ等が出ている状態（不正解）、変色や傷みが見られる状態（不正解）などで構成。
- **ミニ解説機能**: クイズ回答後、すぐにその食材の選び方（目利き方法、保存方法など）を解説する画面を表示。

## 2. 料理・調理システム
- **レシピの選択と食材カスタマイズ**:
  - プレイヤーは最初に作りたい「料理レシピ」を選択する。
  - レシピ選択時、初期状態で選ばれている基本食材は外す（チェック解除する）ことが可能であり、別の食材（シーフードや他の野菜など）に自由に変更・追加できる。
  - ただし、明らかにその料理に合わない不味い組み合わせ（例：麻婆豆腐にバナナなど）は、選択肢からあらかじめ除外される。
- **最低必要食材数とクイズ開始制限**:
  - 各料理レシピごとに「最低必要食材数」（および固定必須食材や特定カテゴリの指定）が設定されている。
  - 選択中の食材が各料理の指定条件（最低必要食材数や固定食材）を満たしていない場合、「目利きクイズを始める」ボタンは非活性（押せない状態）となり、条件を満たすまでクイズを開始できない。
- **調理フェーズ（手順並べ替えパズル）**:
  - 目利きクイズ完了後、調理画面へ遷移し、正しい調理手順を組み立てる「穴埋めパズル」に挑戦する。
  - **画面構造**: 画面上部に `◯ → ◯ → ◯ → ……` と穴（スロット）が並び、下部にシャッフルされた手順の選択肢（例：『野菜をそれぞれ切る』『肉を切る』『切った具材を炒める』など）が表示される。
  - **操作方法**: 下の選択肢をすべて使用して穴を埋め、正しい調理の流れを完成させる。
  - **制限時間**: なし（じっくり考えて回答可能）。
  - **工程数**: レシピごとに手順数は異なる（例：カレーライスは6工程など）。
  - **合否判定**: パズルの**正解数が半分以下（50%以下）の場合は失敗判定**となる。
  - **調理パートの点数計算**:
    - `（正解した穴の数 / 全体の穴の数）× 100`（小数点は四捨五入、最大100点）。
- **料理の評価と結果表示**:
  - **成功条件**:
    - **目利きパート（正解率60%以上）** かつ **調理パート（得点率60%以上）** の**両方を達成**した場合、料理は大成功（美味しい料理）となる。
  - **失敗条件**:
    - 目利きパート、調理パートのどちらか一方でも60%未満となった場合、料理は失敗（不味い料理）となる。
  - **結果表示**:
    - 料理終了後は総合結果画面が表示され、各パートの得点と合計スコア、合否判定を確認できる。
    - ※料理の自由命名および「料理図鑑」機能は廃止となり、料理保存の代わりに結果表示のみを行います。

## 3. スコア・ユーザー管理システム
- **ニックネーム・ユーザー管理**:
  - プレイヤーは初回起動時（または名前未登録時）に「ニックネーム」を入力・登録（簡易ログイン）する。
  - プレイヤー固有のニックネームと、これまでに獲得した「累計スコア」が保存・管理される。
- **スコア（点数）計算方式**:
  - 1回の料理ごとに獲得するスコアは、**目利きパート**と**調理パート**の合計値（**最大200点満点**）となる。
  - **目利きパート得点**: `（目利き正解数 / 選んだ食材数）× 100`（小数点は四捨五入、最大100点）
  - **調理パート得点**: `（正解した穴の数 / 全体の穴の数）× 100`（小数点は四捨五入、最大100点）
  - **合計獲得スコア**: `目利きパート得点 ＋ 調理パート得点`（100 ＋ 100 ＝ 最大200点）
  - 例：目利きで3/4問正解（75点）、調理パズルで5/6工程正解（83点）の場合、合計獲得スコアは 75 + 83 = 158点。
- **スコア加算機能（獲得スコアへの反映）**:
  - 上記で算出した合計獲得スコア（最大200点）をそのまま今回の「獲得スコア」としてプレイヤーの累計スコアに加算する。
- **ランキング機能の廃止**:
  - 他プレイヤーとのランキング競争機能は廃止され、自身の累計スコアの記録・蓄積のみを行う。

## 4. 調理レシピ・食材図鑑システム
- **調理レシピ**:
  - プレイヤーがいつでも料理のレシピを閲覧できる機能。
  - 調理パズルで出題される工程よりも少し詳しい情報（火加減、具材を切る大きさ、美味しく仕上げるコツなど）を確認できる。
  - ゲーム開始時点（最初）からすべてのレシピが解放されている。
- **食材図鑑**:
  - ゲームに登場する食材（お肉、お魚、野菜）の詳しい目利き情報や知識を確認できる図鑑。
  - **解放条件**: 目利きクイズでその食材に**正解すると図鑑が解放**される（一度も正解していない食材は未解放・ロック状態となる）。
  - 解放された食材は、店頭での見分け方のコツ、旬の時期、適切な保存方法などの実用的な詳細情報がいつでも閲覧可能になる。
